## Описание задач

1. **task1.asm** — Программа принимает целое число и проверяет, совпадает ли оно с номером студента.
2. **task2.asm** — Программа выводит диапазон значений от min(x, y) до max(x, y) с заданным шагом.
3. **task3.asm** — Программа считывает массив целых чисел из стандартного ввода до достижения лимита или ввода нуля.

## Среда разработки

Код написан и протестирован в симуляторе [RARS](https://github.com/thethirdone/rars).
